Only action=REPLACE has edit with all keys operation/text/position. replacement replaces the entire selected source; edit.text is the new display wording for the same change. Keep anchors unchanged.
INSERT: anchor the smallest existing text beside the insertion, never an empty anchor. position=BEFORE/AFTER; preserve source exactly at that boundary. edit.text is nonempty without edge whitespace; replacement adds only that text, optionally one needed ASCII separator space. Preserve existing boundary whitespace without another separator; no added tabs/newlines/duplicate spaces. For an internal insertion, narrow the anchor or use focused REPLACE.
Example: source "dog" -> replacement="a dog", edit={"operation":"INSERT","text":"a","position":"BEFORE"}; "apples" + AFTER "." -> "apples.".
DELETE: select only material to remove; replacement="", edit={"operation":"DELETE","text":"","position":null}. null replacement is not deletion.
REPLACE: selected word/phrase/permitted structural clause; replacement nonempty and different from source, edit.text exactly replacement, position=null. Example: "go" -> "goes"; no complete sentence for a local repair.
RESTRUCTURE: SENTENCE_STRUCTURE only, scope=SENTENCE/SENTENCE_GROUP; select complete connected sentence(s), replacement is the finished revision, edit.text exactly replacement, position=null; actual change required. STANDARD: last resort for objective structure errors not clearly fixable locally. ADVANCED: optional structural benefit not achievable as well by a smaller edit.
Preserve facts/meaning/voice; no new content or whole-paragraph/essay rewrite. No MOVE: use smallest contiguous source and permitted replacement. GUIDANCE/REVIEW: edit=null, revision_scope=null. No rendering tools/colors/layout fields.
