## 5. 비용 추정

### 적용 단가와 가정

2026-11-06 확인한 `gpt-6.1-terra` Standard 단가를 적용했다. 단위는 100만 토큰당 USD다.

| 종류 | 단가 |
|---|---:|
| 일반 입력 | $1.00 |
| 캐시 읽기 | $0.05 |
| 캐시 쓰기: 30분 | $1.25 |
| 캐시 쓰기: 12시간 | $2.50 |
| 출력: 추론 포함 | $5.00 |

단가 근거: [OpenAI 공식 GPT-6.1 Terra 모델 문서](https://developers.openai.com/api/docs/models/gpt-6.1-terra).

기본 캐시 보존 기간은 30분이다. 캐시 쓰기 단가는 일반 입력에 추가로 더하는 요금이 아니라,
해당 입력 토큰에 적용하는 별도 단가다.
[OpenAI 공식 캐시 보존 기간·과금 설명](https://developers.openai.com/api/docs/guides/prompt-caching)
