# AUTEDI 통합 서비스 기능명세서

> 회원가입, 로그인, 공통 화면, 홈, AI 첨삭, 학생 관리, 선생님 관리, 계정 관리를 하나의 문서로 정리한 MVP 기능명세서입니다.
>

## 0. 적용 기준

### 0.1 요구사항 우선순위

| 우선순위 | 기준 | 적용 방식 |
| --- | --- | --- |
| 1 | 사용자가 작성한 최신 요구사항 | 기능 범위와 정책의 최우선 기준으로 적용 |
| 2 | 업로드된 화면 | 화면 구성, 필드, 버튼, 상태 표현에 반영 |
| 3 | 학생·선생님 관리 프로토타입 | 목록, 프로필, 팝업, 검색·필터 동작 보강에만 참고 |
| 4 | 기존 Notion 기능명세서 | 문서 형식과 AI 첨삭 세부 동작을 정리하는 데 참고 |

### 0.2 사용자 역할

| 역할 | 접근 가능 기능 | 접근 제한 |
| --- | --- | --- |
| 원장님 | 홈, AI 첨삭, 학생 관리, 선생님 관리, 계정 관리 | 없음 |
| 선생님 | 홈, AI 첨삭, 학생 관리, 본인 계정 관리 | 선생님 관리 메뉴와 관련 URL 접근 불가 |

### 0.3 핵심 확정 원칙

- 선생님은 원장님이 보낸 초대 링크를 통해서만 회원가입한다.
- 회원가입 화면의 기관명은 초대 정보로 미리 정해지며 사용자(원장님 아닌 그 외)가 수정할 수 없다.
- 학습지 업로드 지원 형식은 JPG, PNG로 한정한다.
- 네 개 첨삭 영역마다 `Standard` 또는 `Advanced`를 독립적으로 설정한다.
- 성장 리포트에는 매트릭스·히트맵을 사용하지 않는다. 영역별 오류 변화는 선 그래프로 제공한다.
- 임시 저장과 최종 저장 모두 홈의 최근 작업과 학생의 첨삭 결과물에 반영한다.
- 선생님 관리 메뉴와 화면은 원장님 계정에만 노출한다.

## 1. 전체 사용 흐름

| 단계 | 사용자 행동 | 시스템 결과 |
| --- | --- | --- |
| 1. 선생님 초대 | 원장님이 선생님 이름과 이메일을 입력해 초대 메일을 보낸다. | 초대 대기 계정을 만들고 기관이 포함된 회원가입 링크를 발송한다. |
| 2. 회원가입 | 선생님이 초대 링크에서 이름, 이메일 형식 아이디, 비밀번호를 입력한다. | 기관에 소속된 선생님 계정을 생성하고 로그인 화면으로 이동한다. |
| 3. 로그인 | 사용자가 이메일과 비밀번호를 입력한다. | 권한에 맞는 홈과 사이드바를 표시한다. |
| 4. 학습지 업로드 | JPG 또는 PNG 학습지를 등록한다. | 원본 미리보기와 파일 관리 기능을 제공한다. |
| 5. 첨삭 설정 | 제목, 학생, 네 개 영역의 AI 개입 수준을 설정한다. | 작업 건과 분석 설정을 저장한다. |
| 6. AI 첨삭 생성 | 첨삭 생성을 실행한다. | 오류 수정, 개선 제안, 수정 이유를 생성한다. |
| 7. 첨삭 검토 | AI 결과를 확인하고 수정·삭제하며 수기 첨삭을 추가한다. | 교사가 승인한 첨삭 상태를 작업 건에 반영한다. |
| 8. 저장 | 임시 저장 또는 최종 저장을 선택한다. | 학생 이력과 홈 최근 작업에 상태를 반영한다. |
| 9. 학생 관리 | 학생별 성장 리포트, 결과물, 기본 정보, 메모를 확인한다. | 누적 첨삭 데이터를 그래프와 AI 인사이트로 제공한다. |
| 10. 선생님 관리 | 원장님이 선생님 정보와 첨삭 이력을 확인한다. | 초대·활동·퇴사 상태와 교사별 활동 내역을 제공한다. |

## 6. 성장 리포트 데이터 기준

| 항목 | 기준 |
| --- | --- |
| 집계 대상 | 최종 저장된 `완료` 결과물 |
| 집계 단위 | 결과물별·첨삭 영역별 오류 수 |
| 길이 보정 | `(해당 영역 오류 수 ÷ 인식된 총 단어 수) × 100`으로 100단어당 오류 수 계산 |
| 날짜 기준 | 최종 저장 완료일 |
| 그래프 해석 | 값이 낮아질수록 오류가 감소해 개선된 것으로 해석 |
| 점 선택 정보 | 날짜, 결과물 제목, 영역별 오류 수, 대표 수정 내용, 결과물 바로 가기 |
| 데이터 부족 | 최소 결과물 수 미충족 시 추세를 단정하지 않고 안내 문구 표시 |

## 7. 공통 빈 화면·오류 처리

| 상황 | 처리 |
| --- | --- |
| 검색 결과 없음 | 검색어·필터를 초기화할 수 있는 안내와 버튼 제공 |
| 목록 데이터 없음 | 첫 등록·첫 초대·첫 첨삭으로 이어지는 CTA 제공 |
| 네트워크 오류 | 입력·편집 내용을 가능한 한 유지하고 재시도 제공 |
| 권한 없음 | 데이터를 노출하지 않고 접근 불가 안내 후 허용된 화면으로 이동 |
| 세션 만료 | 로그인 화면으로 이동하되 저장되지 않은 작업 복구 가능 여부 안내 |
| 중복 실행 | 저장·생성·초대 요청 처리 중 버튼을 비활성화하고 진행 상태 표시 |
| 팝업 닫기 | 저장되지 않은 입력이 있으면 닫기 전 확인 |

## 8. 개발 전 확정할 정책

### 우선 확정 필요

1. 업로드 파일당 최대 용량과 한 작업의 최대 이미지 수
2. 첨삭 검토 화면에서 제목과 학생을 바로 수정할 수 있는지 여부
3. 완료 결과물을 다시 편집할 수 있는지, 가능하다면 버전을 어떻게 보존할지
4. 선생님 목록의 `이번 달 첨삭 수`에 임시저장을 포함할지 여부
5. 선생님 첨삭 이력의 `전체 기간` 필터 제공 여부와 페이지네이션 방식
6. 선생님 정보에서 계정 이메일을 수정할 수 있는지 여부
7. 학생 기본 정보에서 학생 이름도 수정할 수 있는지 여부
8. 학생 메모의 수정·삭제 허용 범위와 감사 이력 보존 방식

### 운영·보안 정책

1. 선생님 초대 링크의 만료 시간, 재발송 횟수, 초대 취소 방식
2. 동일 이메일의 기관 간 중복 가입 허용 여부
3. 퇴사 처리 취소 또는 재입사 복구 방식
4. 자동 저장 주기, 임시 작업 보관 기간, 동시 편집 충돌 처리
5. 비밀번호 변경 시 현재 비밀번호 확인과 로그인된 다른 기기 세션 종료 여부
6. 학생·보호자 연락처의 열람 권한, 마스킹, 보관·파기 정책
7. 성장 리포트 AI 인사이트 생성에 필요한 최소 완료 결과물 수
